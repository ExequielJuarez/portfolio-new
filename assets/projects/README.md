# Capturas de proyectos

Guardá acá una captura de cada proyecto (formato 16:10, `.webp` o `.png`) con estos nombres:

tienda-ropa.webp, tienda-hombre.webp, tienda-2.webp, kioscos.webp, ventas.webp,
restaurante.webp, bugueria.webp, sushi.webp, landings.webp

Los nombres se definen en `js/main.js` (array `PROJECTS`).
